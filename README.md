# 工作日历

一个纯前端、无需登录的工作日历，可直接部署到 GitHub Pages。

## 功能

- 分类管理“长期做”“当天做”“每周做”“任务和收获”
- 只显示周一至周五
- 长期任务进展时间轴
- CSV、JSON 和打印/PDF 导出
- JSON 备份导入

## 数据与隐私

所有日历数据只保存在当前浏览器的 `localStorage` 中，不会上传到 GitHub。换浏览器、换设备或清理缓存前，请先使用“备份全部 JSON”，然后在新环境使用“导入 JSON”恢复。

## 部署

仓库根目录的 `index.html` 可直接由 GitHub Pages 托管，不需要构建步骤或第三方依赖。
